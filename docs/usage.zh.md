# CCBaga 使用与风险说明

[English](usage.md) · 简体中文

核对日期：2026-10-12，依据包含 0.2.34 功能的当前仓库代码。可从侧栏或「傻瓜设置」首页提示打开「使用说明」。界面语言切换只改变界面，不改变电脑或浏览器语言。

政策有生效日期：Anthropic 的 Usage Policy 主页面已展示 **2026-11-12** 生效的更新，公告发布于 10 月 8 日；此前版本生效于 **2025-09-15**。下文分别列出两版来源，不将已公布但未生效的版本当作现行规定。官方政策和产品行为可能继续变化。

## 项目实际管理什么

CCBaga-A 管理本机白名单内的 Claude Code/Claude Desktop 数据、独立浏览器 B 的生命周期与观测，以及部分系统设置。B 通过随机令牌的回环会话向 A 回报测量。网络页提供固定资源入口及独立 Network Skill 的安装提示词。

本项目不能验证或修改 Anthropic 服务器账号状态，也不能保证平台接受某种环境。「绿色核验」仅表示列出的实测项目在当时匹配；它不是匿名、隐私或账号安全保证。切换 IP、指纹、语言、时区，或清理本地数据，不会删除服务器记录、解除封禁或改变支持地区资格。

## 页面与功能

### 傻瓜设置

选择地区只是准备后续动作，单独选择不会立即修改环境。

- **清理浏览器缓存**：先退出 B，清理列出的缓存；登录、书签和密码保留。原先运行的 B 会重新启动，原先关闭的则保持关闭。
- **切换浏览器指纹**：退出并重启 B，更新种子及地区语言/时区，清空显式浏览器代理以跟随 TUN。先保存浏览器工作，再核验新出口；不要假定仍沿用原代理。
- **重置时区、语言**：应用所选地区的时区、首选语言和区域格式，可能需要系统授权、重启或注销，不会改变公网 IP。
- **暂存 Claude 身份**：打开身份确认页面，不会立即删除数据。

### Claude 身份管理

先保存 Claude 工作，展开「保留在工作区」检查选择。勾选的分类留在工作区，未勾选的随当前身份暂存；登录与身份数据始终随身份。Skills、插件、MCP、个人设置、项目记录、会话历史、缓存可分别选择。项目源代码不扫描；自定义 Claude 资料目录可能不在管理范围内。

核对当前身份名称、目标和保留分类后再确认。确认后会停止已识别的 Claude 进程，未保存任务可能中断。每次切换先保存离开的本地状态，再恢复目标。「空身份」留下新的本地工作区，不表示设备隐身或服务器上没有记录。若提示未完成的事务，先使用恢复操作。服务器登录已失效或撤销时，恢复本地数据后仍可能需要重新认证。

**直接删除**会删除当前登录/身份数据和未勾选保留的分类，不创建新归档；已有暂存身份保留。删除暂存卡片仅删除该归档，不修改当前工作区。两者均需确认，应用无法撤销。加密本地归档不等于外部备份或服务器账号备份，也不保证隔离同一用户或管理员。

### 浏览器与电脑环境

保存指纹/代理设置和清空站点数据前，先退出 B。清理缓存保留登录；**清空站点数据**还会删除列出的 Cookie、站点存储与恢复会话，不创建备份。**设为默认浏览器**需要操作系统确认。

**对齐美国系统环境**先核验美国出口，再修改电脑时区、语言、区域和定位设置；不会切换代理节点。浏览器、机器和不同域名的流量可能走不同路由，出口检测服务的结果不能证明所有 Claude 流量都走同一路径。DNS/WebRTC 泄漏没有独立验收。

电脑页展示当前状态与目标草稿；时区、语言、定位分别应用，可能需要系统授权、重启或注销。系统权限未知时不能当作已关闭。

### Network Skill

应用不收集 SSH 密钥或代理凭据，也不执行远程部署。选择你的 AI 工具并复制提示词；独立 Skill 在该工具中运行。执行前核对路径、服务器、密钥和命令，明确批准实际远端变更。代理/VPS 只改变网络路径，不改变 Anthropic 的服务规则或支持地区资格。

### Claude Code CLI 与更新

身份页内可检测 CLI 安装方式及版本。确认卸载/重装后会停止已识别的 Claude 进程；程序维护保留身份保险库和个人资料。重装需要联网。原生安装器下载/解析预检失败时可在卸载前停止，但后续安装失败不保证完整回滚，可能留下部分安装状态；先看日志及实际状态再重试。

**检查更新**只检查可用版本，安装需用户选择。Windows 安装包更新 A/B 并先关闭 B；macOS 应用内更新仅更新 A，B 用完整 DMG；Linux 使用安装包、包管理器或源码更新。安装和重启前保存工作。

## 遇到访问限制

1. 保存完整提示、时间、登录方式和工单。不要向第三方发送密码、Cookie、会话令牌、API Key 或完整支付资料。
2. 区分普通登录错误、用量限制、[服务故障](https://status.claude.com/)与明确的暂停/终止通知。若个人账号正常而组织暂停，使用该组织的 **Request a review**。
3. 若账号明确暂停或终止，用受影响账号登录 [claude.ai/restricted](https://claude.ai/restricted) 提交官方申诉；表单需要登录。被封 Free/Pro/Max 用户可在该页面使用导出/删除入口，但导出范围可能受违规类型限制。
4. 不借新账号、共享账号或未经授权中转绕过封禁。申诉结果、处理时间、数据可用性及退款以官方适用规则和购买渠道为准，本项目不作保证。
